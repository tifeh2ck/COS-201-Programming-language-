# COS-201-Programming-language-
## Week 3: Variables, Data Types, Expressions and Input/Output

### Programs
- `SimpleCalculator.java`: adds, subtracts, multiplies and divides two numbers.
- `AverageCalculator.java`: calculates the total and average of three scores.
- `ItemCost.java`: calculates the total cost of an item from its price and quantity.

### How to compile and run
Open a terminal in the `week03` folder and run:

```
javac SimpleCalculator.java
java SimpleCalculator

javac AverageCalculator.java
java AverageCalculator

javac ItemCost.java
java ItemCost
```
